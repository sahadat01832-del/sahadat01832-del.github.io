Where the app runs

The assistant itself is self-hosted: it runs on the operator's own machine and is reachable through the live link on this page. These static pages are always available, so the product stays findable even when the app itself is offline.

About this site

Static pages hosted on GitHub Pages. No advertising or analytics trackers, no cookies for visitors, nothing to sign up for in order to read it — built as plain HTML and CSS, so they load on any phone with a weak connection.
